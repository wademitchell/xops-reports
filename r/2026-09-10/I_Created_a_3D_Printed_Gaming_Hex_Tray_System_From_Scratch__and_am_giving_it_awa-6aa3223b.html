Key ideas

The main use case is tabletop organization: individual trays keep tokens and pieces separate, then join into a larger play-area layout. The creator's current model page says the trays are magnetic on all sides and stack via a recess in the base.

The magnetic system is designed around concealed magnets. The official model page specifies 12 x 3 mm round magnets in its bill of materials and says the print does not need glue, a print pause, or supports.

Correct magnet orientation matters. The model page says each tray has an arrow that indicates magnetic north so matching trays can be joined predictably.

The system is an expandable family rather than a single bin. The video description points to toppers, removable dividers, travel clips, a magnet funnel, a drink tray, and a non-magnetic locking alternative.

The creator's project library has evolved since this video. The Patreon collection currently lists newer LITE and economy variants; those may not match the exact version demonstrated.
