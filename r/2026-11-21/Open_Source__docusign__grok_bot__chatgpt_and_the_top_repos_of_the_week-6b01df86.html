Andrew Warner and Adam highlight ten projects for making AI-assisted software easier to plan, build, review, and test, plus three bonus picks. Their recurring point: give agents a purpose-built tool and clear instructions instead of making them guess how to do the job.

Source basis

Full YouTube captions through the sign-off, supplemented by non-verbatim video review notes for the on-screen ranking. Project names and links were checked against the creator's description and official sources. This is a weekly GitHub roundup, not a head-to-head test; Andrew notes gaps in his historical star charts.

Key ideas

Bonus: SignuDoc is a self-hosted document-signing tool. Andrew liked that it offers a Vercel deploy button instead of leaving users to figure out hosting. 0:30

Bonus: Lastbook bundles offline reference material, maps, videos, and a local AI model. Adam liked being able to look things up without an internet connection, as long as his computer is working. 1:29

Bonus: OpenMausBot is an open alternative to Grok Bot that gives assistants their own virtual computers. Andrew says he connected Codex successfully and liked that people can join the chats. 2:26

Creator's key callouts

First Stars: The description lists Patina, a dual-pane Mac file manager, but Andrew deferred the segment after the list disappeared from his screen. No on-air review. 29:58

Unused AI allowance: Adam says he saves spare capacity near a subscription reset for a second quality check, such as revisiting transcript accuracy, matching records, or looking for things an earlier pass missed. He describes using T3 Code to coordinate the work. 30:25

YouTube Shorts: Andrew says his editor uses ChatGPT to make clips and gives it specific editing notes, such as cutting away when Andrew silently sips tea. Andrew reports that some clips drew thousands of views. 35:18

Creator's ranking

1

Plannotator

Comment directly on a coding agent's plan and send the notes back in one go. Both hosts preferred this to referring to numbered paragraphs in chat; Adam liked having the same review interface every time. 3:32

github.com
2

Stitch Skills

Gives a coding assistant instructions for using Google's Stitch to design app screens. Adam's point: the connector gives the assistant access; the skills tell it which steps to take and in what order. 6:00

github.com
3

Modern Web Guidance

The Chrome team's web-development guidance for coding agents. Andrew liked the rationale: agents can fall back on old, heavy JavaScript patterns when a modern browser already has a built-in solution. 9:00

github.com
4

Open Code Review

Alibaba's automated code-review tool. Adam saw its value when a prototype starts serving paying customers and reliability matters more; he also liked the option of using lower-cost models. 12:13

github.com
5

Last 30 Days Skill

Pulls recent signals from sources such as Reddit, X, and YouTube. Andrew highlighted new inputs such as patents and job postings; Adam said the idea inspired an internal briefing from recent calls and messages. 13:28

github.com
6

Chrome DevTools MCP

Lets a coding agent test and debug in real Chrome. Adam uses it for Chrome extension work and finds direct browser access less cumbersome than having the agent click around by screen control. 15:42

github.com
7

Claude Trading Skills

A toolkit for market research and portfolio review. The hosts framed it as a way for hobby traders to check their work, not as a bot that trades for them; Andrew was surprised it made the top ten. 18:33

github.com
8

AG-UI

Standardizes the messages between an agent and the app showing its work, such as when a reply starts streaming or a tool runs. Adam liked that it handles those events without dictating what the app looks like. 20:17

github.com
9

Astryx

Meta's library of reusable interface components, including a chat template. Adam found Material UI easier for people to browse but said he prefers starting new agent chats from the Astryx template. 23:34

github.com
10

HermesEnabler

An unofficial project for making Hermès watch faces available on other Apple Watch models. The hosts saw it as a novelty, not something they expected to use.
