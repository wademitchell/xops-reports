Key ideas

The description frames an experiment with three differently behaving bees and $1,000 split between them. Its chapters describe funding the exchange and one sub-account per bee, but do not establish investment returns or which bee wins. Video

The creator's sequence goes from OKX's Agent Trade Kit to building the bot with Claude Code, assigning separate API keys, testing Jev calls, and showing a dashboard. The repository says Jev chooses among valid moves while plain code can veto or resize orders, impose stops and spending caps, and log decisions before action. Repository

The three styles in the current repository are Bizzy/Breakout on selected major coins, Breezy/Trend on BTC and ETH, and Boozy/Momentum across liquid coins. These are code-defined strategies with AI selecting a move, not three unconstrained autonomous portfolio managers. Strategy descriptions

The description then moves to a persistent VPS, domain and deployment, a demo-trading test, and the public beebots.tech dashboard. This explains the always-on presentation; hosting and model calls still have operational costs. Setup and settings

Paper mode is the default. The README requires several manual acknowledgments and exchange credentials for live mode, and warns that losses can be total. A public leaderboard is optional and paper-only for user-created bees; neither that leaderboard nor a brief live run validates a trading edge. README
