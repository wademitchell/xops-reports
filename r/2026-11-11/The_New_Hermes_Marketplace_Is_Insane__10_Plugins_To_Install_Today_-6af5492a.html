Sharbel counts down ten ways to expand Hermes, from building Blender models to using an existing Claude subscription. His top three are Claude Subscription, Telegram Business, and Connectors. He says he tested all ten, but several need extra software, careful permissions, or an experimental-feature warning.

Source basis

Full timestamped English captions through the closing remarks, supplemented by full-video Gemini viewing notes (not verbatim captions) and the creator's written guide. Direct Marketplace pages were independently opened to confirm the featured resources. Links below use those source-provided pages; this is a summary of Sharbel's ranking, not an installation test.

Creator's key callouts

Start with Claude Subscription if you already pay for Claude, then add other capabilities one at a time. The general installation command he shows is hermes plugins install followed by the plugin name; desktop installation is another option.

He explains Official, Verified, and Community labels as signals about who supplies a plugin. His written guide explicitly warns that a label is not a guarantee of safety.

Creator's ranking

1

Claude Subscription

Sharbel's #1: use a Claude Pro or Max plan through Claude Code while keeping Hermes' memory, skills, and tools. He puts it first for people already paying for Claude who also pay separate API charges. His setup: install and sign into Claude Code, install claude-subscription-directsdk, then choose Claude Subscription in hermes model or /model. It is experimental, consumes the plan's allowance, and he recommends turning off Extra usage to avoid overage charges. Chapter start 8:01.

2

Telegram Business

Sharbel's #2: draft customer replies without sending them automatically. Each draft comes to the owner with Send, Edit, and Discard buttons; the customer gets nothing until Send is tapped. He likes it for business owners interrupted by constant messages. Requires a Telegram Business subscription. Chapter start 7:34.

hermes-agent.nousresearch.com
3

Connectors

Sharbel's #3: connect apps such as Slack, Notion, and Stripe through a browser sign-in instead of manually handling API keys. He demonstrates Notion and describes 54 apps at filming. His practical tip: restrict permissions, such as allowing reading and writing without deletion; keep a financial app like Stripe read-only. Chapter start 6:54.

hermes-agent.nousresearch.com
4

Workflow Record

Sharbel's #4: demonstrate a repetitive browser task once, record it, and use /learn to turn the demonstration into a reusable skill. He likes avoiding a long explanation of every click. Works in Chromium-family browsers; password fields are hidden, but ordinary text fields are saved, so he warns against recording private information. Chapter start 6:12.

hermes-agent.nousresearch.com
5

Agent Importers

Sharbel's #5: bring an existing Claude Code, OpenClaw, Codex, or Grok Bot setup into Hermes instead of rebuilding months of configuration. He describes moving instructions, memories, skills, and connected tools with hermes import-agent. He emphasizes previewing changes and importing Grok Bot routines paused to avoid duplicate runs; see the exception to his API-key claim below. Chapter start 5:19.

hermes-agent.nousresearch.com
6

Oh My Hermes

Sharbel's #6: add a workflow that asks questions, makes a plan, chooses models for different parts, and checks the result before declaring success. His example is building a website about the Marketplace. He likes the added organization but says it substantially changes Hermes, so it is for experienced users rather than day one. Chapter start 4:22.

hermes-agent.nousresearch.com
7

Memory Wiki

Sharbel's #7: browse topic pages, daily activity logs, and the persistent information Hermes carries into chats. He likes finally seeing what the agent remembers. The viewer is read-only; corrections are made by asking the agent rather than editing through the wiki. Chapter start 3:49.

hermes-agent.nousresearch.com
8

Phone Harness

Sharbel's #8: let Hermes open apps, tap, type, and read a real phone's screen. iPhone control uses iPhone Mirroring on a Mac; Android is also supported. He says password and two-factor prompts are handed back to the user. His immediate precaution is to run hermes tools and disable Phone Harness for Telegram so chat access does not expose phone control. Chapter start 2:59.

hermes-agent.nousresearch.com
9

LetsFG

Sharbel's #9: search flights and hotels across airlines, travel sites, city airports, and split tickets without juggling tabs. His example is Amsterdam to London with accommodation. He emphasizes that bookings require the user's email approval and card details belong on LetsFG's website, never in chat. Chapter start 2:13.

hermes-agent.nousresearch.com
10

Blender

Sharbel's #10: describe a model and let Hermes inspect and change a Blender scene. His example is a personalized desk phone stand. He calls it the fun option, says Blender 5.1+ and the MCP add-on are needed to use it, and warns it can run code inside Blender, so use it only on your own projects. Chapter start 1:28.

Caveats

Current Marketplace descriptions add two material qualifications: Workflow Record and Telegram Business are Nous-built Labs plugins marked unsupported, and Agent Importers can copy OpenClaw secrets if the user explicitly chooses --migrate-secrets. Sharbel's blanket statement that API keys are never copied is therefore too broad. The direct pages above document these details.
