Beau covers five fast-growing projects that give AI agents memory, a more disciplined coding process, or a shared control panel. Creator's ranking

1

T3 Code

#1 by weekly growth: +9,770 stars in Beau's snapshot. A shared control panel for Claude Code, Codex, Cursor and other coding agents, accessible from desktop, web and phone. Beau highlights coordinating agents, such as having Claude plan and Codex build, without juggling separate terminals. He considers it useful if you already use multiple coding agents. His warnings: the project is still early, new threads default to Full access, analytics are enabled by default, and Claude usage through its integration can consume the five-hour allowance faster. He advises choosing more restrictive permissions and disabling analytics. Chapter: 10:35.

2

claude-mem

#2: +7,255 stars. Saves short notes about an agent's work so the next session can pick up where the last one stopped. Beau describes an inexpensive model summarizing tool activity into local storage, with a briefing of recent observations brought into the next session. He likes the idea but says to wait because of a serious privacy incident: browser setup uploaded recent prompt history without asking. The project's v15.8.3 release notes confirm the consent fix and explicitly say earlier uploads are not removed by the update. Chapter: 07:54.

github.com
3

ECC, formerly Everything Claude Code

#3: +6,201 stars. A large collection of ready-made agent roles, skills and automatic checks: Beau cites 71 agents, 314 skills, 98 commands and 27 hooks. It can load project context, check commands, review work and record recurring lessons. Setup offers minimal, standard and strict check profiles. His preference is to borrow a few useful skills rather than install everything: he roughly estimates about 30,000 tokens of descriptions if all are listed, versus around 1,400 for Superpowers. He advises checking /context and using official sources because unofficial copies may contain malware; the official README also warns about mirrors. The background learning observer is off by default. Chapter: 05:26.

github.com
4

Superpowers

#4: +5,956 stars, but Beau's first choice to install. It makes a coding agent clarify the goal before writing code, work in a separate workspace, split the plan into two-to-five-minute tasks, write a failing test before the fix, and review the result. Beau calls it a comparatively lightweight way to improve how an agent works. His exceptions: all that process can be excessive for a one-line change, and a fresh helper agent for every task can burn through usage limits. Chapter: 03:11.

github.com
5

TradingAgents

#5: +4,603 stars. A simulated investment-research team: analysts gather evidence, bullish and bearish agents debate it, a trader proposes a position, risk agents challenge it, and a portfolio manager makes a final call. Beau finds the pattern educational, not a reason to trust it with money. He notes support for running with a ChatGPT Plus or Pro subscription, but warns that the paper's impressive returns come from a short three-month 2024 historical test and that the many-agent process uses substantial model calls. It does not place real trades. His closing advice is to study the design, not trade on it. Chapter: 00:53.
