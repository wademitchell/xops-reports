Key ideas

Mods are JavaScript or TypeScript handlers packaged in Claude Code plugins. Unlike a skill's instructions or an external settings hook, they can draw interactive panes and respond inside the app to prompts, turns, or tool calls. That makes a control at the moment of an edit possible, but also gives it substantial access.

Nate says he first had Claude inspect repeated work and friction in his session logs, request five mod ideas, and select only the ones worth making. This is a design method, not a reason to give arbitrary third-party code access to private logs; narrow the input and review the generated code. Creator article; Anthropic creation guide.

Next Steps offers clickable suggestions after a turn. Nate's example suggested tidying old tasks and moving due dates, which he found less useful than potential app-development suggestions. Suggestions are not approvals or evidence that a task should be changed. Creator account.

Cache Keeper displays context, usage limits, an API-equivalent cost estimate, and a cache timer above the prompt; buttons run Nate's session-handoff and clear-and-continue flow. The timer and savings are local interface estimates, not a verified bill or a guarantee that a particular request will use cache. Creator account.

Recording Mode masks sensitive values in the visible chat for screen sharing while the agent still uses the real values. Nate's example updated an HTML price even though the displayed values were hidden. This is presentation masking, not secret removal from files or other windows, and is not a general privacy control. Creator account.

Goal Meter shows the task list, elapsed time, and completion progress of Nate's /goal sessions; a fuller view includes other chats. His comment-analysis example had four visible stages, but elapsed time is not a reliable remaining-time estimate. Creator account.

Collision Guard checks edits, writes, and notebook edits against files another chat touched in the last 30 minutes. In Nate's pricing-page example, it offered proceed, move to a worktree, cancel, or another instruction before a second chat wrote the file. This is a human decision point, not demonstrated prevention of every collision or a replacement for isolated worktrees. Creator account.
